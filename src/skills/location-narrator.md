# 位置感知讲解

## 工作流程

1. 调用 get_location 获取精确坐标和地址
2. 调用 search_nearby 搜索半径 1km 内的 POI
3. 调用 get_weather 获取当前天气（如果尚未获取）
4. 综合信息，生成讲解

## 讲解内容层次

### 即时环境（50m 范围）
- 当前所在的地形：山脊、溪谷、林间、草地
- 明显的地标：大石头、古树、溪流
- 当前海拔和坡度（如果 GPS 精度足够）

### 周边景点（1km 范围）
- 距离最近的 3-5 个兴趣点
- 每个用一句话概括
- 标注方向和步行时间

### 区域背景
- 所在山脉/景区的概况
- 海拔带和植被类型
- 当季特色（花季、红叶、雪景）

## 讲解格式

"📍 **[当前位置描述]**
海拔约 [X] 米 | [天气简述]

[2-3 句环境描述]

附近值得注意的：
- [景点1] — [方向+距离] — [一句话]
- [景点2] — [方向+距离] — [一句话]"
