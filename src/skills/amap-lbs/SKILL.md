# 高德地图 LBS 能力

## 可用工具

### search_nearby — 附近搜索
搜索用户当前位置周边的兴趣点（POI），支持关键词过滤。

### plan_route — 路线规划
从用户当前位置到目的地的路线规划，支持：
- **步行** (walking): 适合短距离徒步，显示详细步行指引
- **驾车** (driving): 适合自驾游，提供多条路线选择
- **骑行** (riding): 适合骑行路线
- **公交** (transit): 公共交通方案，含换乘指引

### plan_travel — 智能旅行规划
根据用户位置和偏好，自动生成一日游/多日游行程安排。

## 使用策略

### 找地点
用户说"附近有什么""帮我找厕所""哪里有餐厅"→ 调用 search_nearby，设置合适的关键词和半径。

### 查路线
用户说"怎么去XX""从这里到XX多远"→ 先确认目的地坐标（可通过 search_nearby 搜索获得），然后调用 plan_route。
- 徒步场景默认用步行模式
- 长距离可建议驾车或公交

### 规划行程
用户说"帮我安排一天""有什么推荐路线"→ 调用 plan_travel，根据用户偏好设置主题和时长。

## 注意事项
- 所有地图功能需要高德 Web服务 API Key
- 未配置 Key 时，告知用户去设置页填写
- 坐标使用 GCJ-02 坐标系（高德标准）
- 距离和时间仅供参考，实际可能因路况不同
